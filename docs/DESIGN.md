# 디자인 규칙

## 콘셉트

**귀여운 장난감 여권.** 앱 전체가 여권 한 권이다. 실제 여권을 흉내 내지 않고, 둥글고 밝은 놀이용 여권처럼 그린다.

- 여권이 틀이고, 도트 그림은 내용물이다. 캐릭터, 문장, 화살표 같은 그림은 도트로 그린다.
- 실제 국가 문장과 여권 양식은 쓰지 않는다. 앱의 문장은 도트 궁궐이다.
- 그림 자리에 이모지를 쓰지 않는다. 기기마다 다르게 보이고 도트 그림과 어울리지 않는다.

| 화면 | 여권에서의 역할 |
| --- | --- |
| 로그인 | 표지 — 여권 발급받기 |
| 캐릭터 만들기 | 신원 정보 면 — 캐릭터가 증명사진이다 |
| 스탬프 | 사증 면 — 관광지 도장이 찍힌다 |

## 색

바탕은 민트색 하나와 따뜻한 종이색 다섯 단계다. 도장에만 잉크 색 두 가지를 더 쓴다.
`apps/web/src/index.css`의 `@theme`에 정의한다. 화면에서는 색 값을 직접 쓰지 않고 이름으로 쓴다.

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `passport` | `#47E9DB` | 표지, 선택된 탭, 문장의 포인트 |
| `paper` | `#F7F1E6` | 속지 배경, 입력란, 줄 항목, 보조 버튼 |
| `paper-shade` | `#E8DDCA` | 속지의 점 무늬, 탭 바, 기계 판독란, 증명사진 배경, 배지 |
| `paper-line` | `#C9BCA7` | 못 받은 도장의 점선, 사진을 붙인 테이프 |
| `ink-soft` | `#91877B` | 항목 이름 같은 보조 글자, 주 버튼의 그림자 |
| `ink` | `#453F38` | 글자, 테두리, 주 버튼 |
| `stamp-red` | `#C8402B` | 도장 잉크 |
| `stamp-blue` | `#2F5FC4` | 도장 잉크 |

- `passport`는 아껴 쓴다. 표지와 선택된 탭에만 쓴다. 배지, 버튼, 선택 표시에는 `paper-shade`나 `ink`를 쓴다.
- 도장 잉크 색은 도장에만 쓴다.
- 본문 글자는 `ink`로 쓴다. 배경과 명도 대비 4.5:1 이상을 지킨다.
- `ink-soft`는 `paper` 위에서 명도 대비가 약 3:1이다. 짧은 보조 표기에만 쓰고, 꼭 읽어야 하는 글에는 쓰지 않는다.
- `passport` 위의 글자도 `ink`로 쓴다.
- 속지 배경은 `paper` 유틸리티 클래스를 쓴다. 종이색 바탕에 점 무늬가 깔린다.

## 글꼴

Google Fonts에서 받는다 (`apps/web/index.html`).

| 클래스 | 글꼴 | 쓰는 곳 |
| --- | --- | --- |
| `font-display` | Jua | 제목, 버튼, 관광지 이름 |
| `font-body` | Gowun Dodum | 본문 |
| `font-pixel` | Silkscreen | 영문 표기, 숫자 (`PASSPORT`, `2 / 6`) |

- Silkscreen에는 한글이 없다. 한글에는 쓰지 않는다.
- 도트 글꼴은 짧은 영문 표기에만 쓴다. 본문에 쓰면 읽기 어렵다.

## 모양

- **테두리:** `ink` 색 실선 2~4px.
- **모서리:** 버튼과 입력란 16px, 줄 항목 14px.
- **그림자:** 흐린 그림자 대신 아래로 4~5px 내려간 단색 그림자를 쓴다. 눌리는 장난감 버튼 느낌이다.
- **주 버튼:** `ink` 바탕, `paper` 글자, 높이 56px, `ink-soft` 그림자.
- **보조 버튼:** `paper` 바탕, `ink` 테두리 2px, `ink` 그림자.
- **누르는 영역:** 가로세로 44px 이상.
- **표지:** `passport` 바탕 안쪽에 `ink` 점선 테두리(바느질 선)를 두른다.
- **탭 바:** 여권의 색인 탭 모양. 선택된 탭은 `passport` 색이고 더 높다.

## 도장

- **받은 도장:** 잉크 색(`stamp-red`, `stamp-blue`) 실선 4px 테두리 안에 점선 2px 테두리를 한 번 더 두른다. 원 또는 둥근 사각형이다. 조금 기울여 찍는다 (−9°~8°).
- **못 받은 도장:** `paper-line` 점선 3px 윤곽과 관광지 이름만 보여 준다. 기울이지 않는다.
- 모양, 잉크 색, 기울기는 관광지 순서에 따라 번갈아 정한다.
- 도장 안에는 위에서부터 영문 표기, 관광지 이름, 방문일을 적는다.
