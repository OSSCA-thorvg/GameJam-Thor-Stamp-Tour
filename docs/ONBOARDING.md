# 캐릭터 온보딩

로그인한 사용자가 부위를 조합해 자기 캐릭터를 만드는 과정이다. 만든 캐릭터는 홈 맵에 나온다.

## 범위

- 온보딩은 캐릭터 선택만 다룬다. 앱 설명 화면은 없다.

## 흐름

1. 닉네임 입력
2. 캐릭터 선택
3. 홈

- 이미 가입했지만 캐릭터가 없는 사용자는 다음 접속 때 캐릭터 선택 화면을 한 번 본다.

## 캐릭터 구성

- 캐릭터는 부위 그림 다섯 장을 같은 자리에 겹쳐 그린다. 아래 순서대로 그리고, 나중에 그린 그림이 위에 보인다.
  1. 몸
  2. 신발
  3. 옷
  4. 얼굴
  5. 머리
- 옷과 신발이 겹치는 부분은 옷이 신발을 덮는다.
- 몸은 모든 사용자가 같다. 고를 수 없다.
- 옷과 신발은 따로 고른다.

| 부위 | 개수 | 선택 |
| --- | --- | --- |
| 몸 | 1 | 고정 |
| 신발 | 3 | 선택 |
| 옷 | 3 | 선택 |
| 얼굴 | 3 | 선택 |
| 머리 | 3 | 선택 |

- 그림은 모두 13장이다. 조합은 81가지다.

## 그림

- 형식은 PNG다. ThorVG(`@thorvg/webcanvas`)로 겹쳐 그린다.
- 포즈는 서 있는 포즈 하나만 있다. 걷기, 점프 동작은 없다. 이동과 점프는 같은 그림이 움직인다.
- 크기는 32x32다.
- 모든 부위 그림의 크기와 발 기준점(발 가운데)을 똑같이 맞춘다. 어긋나면 부위가 떠 보인다.
- 좌우 반전은 다섯 장을 묶은 전체를 한 번에 뒤집는다.
- 온보딩 미리보기와 맵에 같은 그림을 쓴다.
- ThorVG 그림 규칙은 `docs/THORVG.md`를 따른다.
  - 원래 크기(1배)로 그린다.
  - 좌우에 1px 투명 여백을 둔다.
  - AI 서비스에서 받은 PNG는 `caBX` 블록을 지운 뒤 넣는다.

## 저장과 전송

- 고른 부위(옷, 신발, 얼굴, 머리)는 서버의 사용자 정보에 저장한다. 다른 기기로 접속해도 같은 캐릭터가 나온다.
- 서버는 허용된 부위 번호인지 검사한 뒤 저장한다.
- 맵에 있는 다른 사용자에게 부위 선택값을 함께 보낸다. 모든 사용자가 서로의 캐릭터를 본다.

## 나중에 정할 점

- 한 번 고른 캐릭터를 나중에 바꿀 수 있는지, 바꾼다면 어디서 바꾸는지.
